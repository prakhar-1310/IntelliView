# 🚀 IntelliView – Real-Time Coding Interview & Practice Platform

**IntelliView** is a **full-stack real-time coding interview and practice platform** designed to simulate **real interview environments**. It helps developers prepare for technical interviews through **live collaborative coding**, **one-on-one interview rooms**, **contests**, and **AI-powered assistance**.

> 🎯 Built for interview preparation, mock interviews, and competitive coding practice.

## ✨ Key Features

### 🧠 Coding & Interview Practice
- 🧩 Standalone coding practice section
- 🧑‍💻 Interview-style code editor inspired by **VS Code**
- 🎯 Automatic solution validation using test cases
- 🎉 Visual success animations & instant failure feedback
- ⚙️ Secure, isolated code execution environment
- 🎥 YouTube video solutions embedded per problem
- 💡 AI-generated step-by-step hints powered by Grok API

### 🎥 Real-Time Interview System
- 🎥 One-on-one **live interview rooms**
- 💬 Real-time chat with collaborative coding
- 🔑 Session-based room passwords
- 🔒 Strict two-participant room limit

### 🔐 Authentication & Security
- 🔐 Robust authentication using **Clerk**
- 🔒 Secure session management
- 🛡️ Controlled access for interview rooms

### 🛠️ Admin & Platform Tools
- 🛠️ Admin panel for creating & managing coding questions
- 🗓️ Contest hub showing upcoming competitions
- 📚 Resource library with trending tech articles

### 🤖 AI & Automation
- 🤖 AI-powered coding chatbot (ChatGPT + n8n)
- 💡 AI-based hint generation using Grok API (OpenAI ecosystem)
- 🧠 Background task handling using **Inngest**
- 🤖 AI-assisted pull request reviews via **CodeRabbit**

### ⚡ Performance & Scalability
- ⚡ Fast data fetching & caching with **TanStack Query**
- 🔗 Scalable REST APIs using **Node.js & Express**
- 🚀 Production deployment on **Render (Free Tier)**
